# Phase 1 검증 기록

환경: Windows / PowerShell, rustc 1.97.1 (8bab26f4f 2026-07-14).

## 실행한 검증

- baseline: 기존 cargo test, 0개 테스트 통과.
- 단위 테스트는 CLI, JSON 확장/손상, child/suggestion, 중복/ID 충돌, 수집 상태, 양 pipe 대량 출력, source 위치, 상대 링크, escaping, 출력 복원과 동시 writer를 검증한다.
- 통합 테스트는 실제 Clippy로 clean/cache, warning, -D warnings, compile error, workspace/multi-target/Unicode, output/target-dir/manifest-path 우선순위, metadata 미생성과 일반 폴더 보존을 검증한다.
- 사용자 스크린샷에서 rustdoc flex 구조와 table class 충돌을 발견했다. heading을 main 내부로 옮기고 report-table class로 분리했다. workspace 상대경로를 package 경로에 중복 결합하던 문제도 실패 회귀 테스트 후 수정했다.
- 사용자 피드백에 따라 불필요한 Static diagnostic report 보조 문구를 제거했다.

## 검증 한계

- 앱 내 브라우저는 file:// URL을 정책상 거부했다. 다른 표면이나 서버를 통한 자동 우회를 시도하지 않았다.
- 수정본의 시각 배치, 작은 화면, 키보드 focus, 뒤로 가기/새 탭의 실제 브라우저 확인은 사용자 검토가 필요하다. HTML 구조와 모든 생성 링크/anchor는 자동 검증한다.
- Linux/macOS와 Firefox의 실제 실행은 아직 검증하지 않았다. Rust 1.94는 locked compile check를 통과했으며 전체 통합 테스트는 Windows의 rustc 1.97.1에서 실행했다.
- 공개 정적 호스팅, 검색/category/theme/diff/metadata는 후속 Phase 범위이다.

## 최종 검증

- `cargo build --example cargo_probe --locked`, `cargo test --locked`: 단위 33개와 실제 Clippy 통합 7개, 총 40개 통과.
- `cargo fmt --check`: 통과.
- `cargo clippy --all-targets --locked -- -D warnings`: 통과.
- `cargo +1.94.0 check --locked`: 통과.
- `cargo install --path . --root target/phase-1-install --locked --debug`: 통과. 설치 바이너리 직접 호출과 임시 PATH를 통한 `cargo clippy-html` 실제 보고서 생성을 확인했다. 전역 PATH는 변경하지 않았다.
- 독립 read-only 리뷰에서 4개 중요 문제를 발견했다. 일반 폴더 교체/삭제 위험, Windows 경로 별칭 잠금, 긴 파일의 반복 검증, excluded nested dependency 전체 소스 포함을 각각 실패 회귀 테스트로 재현하고 수정했다.
- 일반 폴더가 backup으로 옮겨진 경우도 재확인하며, 예상하지 않은 데이터는 복원하거나 복구 경로에 보존한다. parent 단위 게시 잠금으로 case-sensitive 설정을 추측하지 않고 별칭 writer를 직렬화한다.
- 사용자 요청으로 사이드바에 crate 문맥을 표시했다. 같은 파일·byte 범위의 span/child/replacement 위치 블록은 합치되 note와 suggestion을 유지한다. 관련 회귀 테스트 통과.

최신 미리보기는 `target/phase-1-preview/index.html`이다. 시각 검토의 남은 항목은 위의 검증 한계에 명시한 대로 수동 확인 대상이다.

## 도움말 문서 링크 수정

`for further information visit https://...` 도움말의 문서 URL을 클릭 가능한 링크로 표시한다. 원래 Clippy 버전별 URL을 보존하며 HTTPS URL만 허용하고, 원문 HTML escaping을 유지한다. 실제 Clippy 도움말 링크가 없음을 실패 회귀 테스트로 확인한 뒤 수정했다. rendered diagnostic fallback은 원문 텍스트 표시를 유지한다.
