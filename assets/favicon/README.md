Source: [official Rust logo artwork and license](https://github.com/rust-lang/rust-artwork/tree/main/logo). The working reference was the user-supplied Rust_programming_language_black_logo.svg, provided on 2026-10-30. It was not downloaded from the upstream repository in this session.

Modifications: removed the R, retained the 32 teeth, gear ring and five inward triangular mounts with transparent holes, recolored the artwork #D34516, scaled to a 32-by-32 viewBox, and added a paperclip in the center. Outside the gear and inside its ring remain transparent. favicon.ico contains 16-, 32- and 48-pixel rasterizations of favicon.svg. Rasterization uses sharp/libvips; Pillow assembles the ICO container. Neither is a runtime or Cargo dependency.
